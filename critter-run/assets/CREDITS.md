# Credits

Everything in `assets/` comes from free, openly licensed sources. Works under CC BY need credit, which is given
here and on the in-game credits screen (`js/credits.js`, the "i" button on the title). CC0 works are credited as a
thank-you. Files were trimmed, resized and compressed for the web (meshopt geometry, WebP textures, MP3 audio); other
changes are noted on each line.

## Runners (`runners/`)

- Characters by [Quaternius](https://quaternius.com): Universal Base Characters and Modular Character Outfits - Fantasy. CC0 1.0. Parts were combined onto one skeleton per character, with hair tints and a slightly larger head.
- Animations (`runners/anims.glb`) from the Quaternius Universal Animation Library 1 and 2 (CC0 1.0), plus "Victory", "Dab" and "Power Up" from [Mesh2Motion](https://github.com/Mesh2Motion/mesh2motion-assets) (CC0 1.0), retargeted to the same skeleton. Hips raised per frame so the feet stay on the ground.
