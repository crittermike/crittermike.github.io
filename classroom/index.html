Open that link once on any other device to connect it.
How to get a database URL — about 3 minutes, free
  1. Go to console.firebase.google.com and press Add project. Name it anything; you can switch Google Analytics off.
  2. In the left sidebar choose Build → Realtime Database → Create Database. Pick the region nearest you and Start in locked mode.
  3. Open the Rules tab, replace everything with this, and press Publish:
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "$room.length >= 12",
        ".write": "$room.length >= 12"
      }
    }
  }
}
  1. Open the Data tab and copy the URL shown at the top — it looks like https://something-default-rtdb.firebaseio.com.
  2. Paste it above, press Connect, then use Copy setup link on your other devices.

Anyone holding the class code can read and change the schedule, so treat the setup link like a password. Nothing here is sensitive, but don’t post it publicly.
